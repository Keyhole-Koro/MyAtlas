MyAtlas ラボ

文書マップの見せ方を、一晩で 14 通り試した
README（順位と提案） 今のビューア

MyComputer の文書マップ（MyAtlas）を、今のビューアより読みやすく見せる方法を探した試作の置き場です。今のビューアは 1 枚のページに全部を詰めていて、層の帯・小さな札・番号の札・点線の枠・交差する矢印が多く、密です。ここではその制約を外し、路線図、マンガ、コードと並べる形、データを追う表など、14 通りの見せ方を作りました。

どの試作も同じデータ（lab/data）を読み、地図とソースに無いことは描きません。どれも独立したレビューを受けて、指摘を直してあります。

地図の中身：70 の節、5 つの層と横断する 3 つ、2 つの流れ（UI の要求 11 手順＋もし 2、CPU 時間 12 手順）、4 枚の中の紙、記録 1 回（Editor で「x」を打った 1 回）。

開き方

  1. 端末で lab に入って配る：
    cd ~/Workspaces/MyAtlas-lab/lab
./serve.sh
  2. ブラウザで http://127.0.0.1:8765/ を開く。カードの画面か「開く」で試作が開く。

データを MyComputer から取り直す時は python3 lab/export.py。くわしくは README。

まずはこの 3 つ

違う役目の 3 つ：コードを読む、全体を見る、初めての人に見せる。

14 の試作（おすすめ順）

順位の理由と、本体のビューアに取り入れることは README に。

点（5 点満点）は、最後の手直しの前に受けた独立レビューのもの。読みやすさ・正しさ（データとソースへの忠実さ）・仕上がり・新しさ。指摘の多くはその後に直っています。「ここが課題」は手直しの後も残っていること。

確かめたこと（2026-11-20）

  • 14 の試作をすべて lab/tools/shot.mjs（1440×900）で開いた。読み込みの失敗も、コンソールのエラーも 0 件。撮った画面は shots/load/。
  • 路線図はマウスと指で駅・線・札を押す試験（metro/tools/check.mjs clicks）がすべて通った。マンガはスマホ幅（390×844）の大きく読む画面で、コマが画面に収まる。端末版は python3 lab/terminal/atlas_tui.py --render ui で図を出す。

ラボは MyAtlas の lab ブランチにあります（main には入れていません）。どのページも同梱したライブラリだけで開けます。node_modules/ と .venv/ は入れていません（要るのは検査の道具だけで、入れ方は各 NOTES.md）。
