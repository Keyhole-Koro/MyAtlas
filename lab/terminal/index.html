ターミナルで見る

文書マップを端末の中で。層は帯、手順は番号付きの線。SSH 越しでも、狭い画面でも。

python3 lab/terminal/atlas_tui.py
atlas_tui.py

読み込み中…

キーでも、画面の番号・箱・タブを押しても動きます

動かし方

Python 3 の標準ライブラリだけで動きます。入れるものはありません。

python3 lab/terminal/atlas_tui.py

図だけを出して終わる（テストや文書に貼る用）：

python3 lab/terminal/atlas_tui.py --render ui
python3 lab/terminal/atlas_tui.py --render cpu --step 5
python3 lab/terminal/atlas_tui.py --render os.gateway --view route --width 60
python3 lab/terminal/atlas_tui.py --list

罫線が崩れる端末（曖昧幅を全角にした日本語向けの設定など）では --ascii、明るい端末では --theme light、点の動きを止めるなら --still。

読み方

  • 今の手順。線も箱の枠も太くなる
  • 通った手順（青）
  • これからの手順（灰）
  • 手順の番号（今・通った・これから）。今の手順だけ動詞も付く
  • 「もし」の手順（ある手順の代わりに起きる。a で見る）
  • 線の形が手順の種類： 呼び出し・読み書き syscall 列を通す（破線） 通知（点線、出る所に ◆） 戻り（長い破線、中が空の矢じり）
  • 関数　置き場（角が丸い）　中に紙がある箱
  • 薄い面は実行の文脈（だれが走らせているか）

python3 lab/terminal/atlas_tui.py --render ui の出力

対話しないで図と手順の一覧だけを出して終わります。端末なら色付き、パイプに流すと文字だけ（--color never）。
